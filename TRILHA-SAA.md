# Trilha: AWS Solutions Architect Associate (SAA)

**Meta:** prova entre **março e abril de 2027** (~18 semanas a partir de 17/11/2026)
**Ritmo:** 2h/semana de teoria (fases 1 e 2) e depois 4h/semana (fase 3)

> ⚠️ Antes de comprar curso/simulado, confira no site oficial a **versão atual da prova**
> (era SAA-C03 até a data deste arquivo). Curso e simulado precisam ser da mesma versão.

## 💰 Antes de tudo: descontos
Tenho o curso **AWS Academy Cloud Foundations** (medalha de treinamento), mas **não** a
certificação Cloud Practitioner, então ainda não tenho o voucher de 50% que vem com uma certificação.
- [ ] Perguntar ao professor/FATEC se a AWS Academy oferece **voucher de desconto** para a prova
- [ ] Decidir: ir direto pra SAA **ou** fazer o Cloud Practitioner antes (se tiver voucher barato,
      passar nele dá 50% de desconto na SAA)

## 📅 Fases

### Fase 1: Base (semanas 1-8) · 2h/semana
- [ ] Assistir ~metade do curso, **na ordem**
- [ ] Ao fim de cada seção, fazer as questões do próprio curso
- [ ] Anotar em `saa-notas.md` só o que você **errou ou achou confuso**

### Fase 2: Completar (semanas 9-14) · 2h/semana
- [ ] Terminar o curso
- [ ] Revisar as anotações

### Fase 3: Simulados (semanas 15-18) · aumentar para 4h/semana
- [ ] Simulado 1 em **modo revisão**: ler a explicação de TODAS as questões, inclusive as que acertou
- [ ] Revisar os temas mais fracos
- [ ] Simulados em **modo prova** (65 questões, 130 min, sem consultar)
- [ ] Agendar a prova quando atingir os critérios abaixo

## ✅ Como saber que você está pronto
Marque a prova quando **todos** forem verdade:
- [ ] **≥ 80%** em pelo menos **3 simulados seguidos** do Tutorials Dojo, em modo prova
      (a nota de aprovação é 720/1000, mas o simulado é parecido com a prova, então 80% dá margem)
- [ ] Consegue explicar **por que** as alternativas erradas estão erradas, não só qual é a certa
- [ ] Domina as "pegadinhas clássicas" sem pensar:
  - quando usar SQS x SNS x EventBridge
  - Multi-AZ x Read Replica no RDS
  - Gateway Endpoint x Interface Endpoint
  - estratégias de DR (backup/restore, pilot light, warm standby, multi-site)
  - classes de armazenamento do S3 e lifecycle
- [ ] Terminou pelo menos os Projetos 02 e 04 (VPC na prática faz MUITA diferença)
